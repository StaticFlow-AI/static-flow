# Xiaohongshu (小红书) Anti-Throttling & Zero Diversion Rule (Hard Rule)

Whenever generating Xiaohongshu (`小红书`) post copy, slide images, or publishing notes via browser automation, strictly obey these anti-throttling (`防限流 / 禁站外引流`) rules:

1. **Never Post Diversion or Link Comments (`严禁引流评论`)**:
   - Never post or pin comments containing URLs (`http://`, `https://`), domain names (such as `ackingliu.top`, `staticflow.cc`, `.com`, `.top`, `.cc`, `.io`), blog pointers, or off-platform prompts ("原文链接", "个人博客", "点主页", "搜同名", "私信领").
   - Once a note is published in Xiaohongshu Creator Center, stop — do not navigate to the note to add blog-link comments.
2. **Never Include Diversion Phrases in Title or Body Copy (`正文严禁引流话语`)**:
   - Never write phrases such as `个人博客`, `已导入博客`, `全文见博客`, `链接放评论区`, `评论区置顶`, `见评论区`, `点击主页`, `私信获取`, or any external URL / domain name in the post title or body.
   - End the post body naturally as a self-contained technical note (e.g., concise engineering takeaway or pure technical question).
3. **Never Render Domains or Diversion Text on Slide Images (`配图严禁域名与导流字样`)**:
   - Xiaohongshu OCR scans all slide images. Never put `ackingliu.top`, `staticflow.cc`, any `.top`/`.com`/`.cc` domain, QR codes, or text like `完整精翻入库` / `全文见博客` / `链接见评论区置顶` anywhere on cover/content/summary slides (including headers and footers).
4. **Skill Reference**:
   - Follow `skills/xiaohongshu-tech-note-publisher/SKILL.md` for visual style, character limits, and Creator Center upload mechanics.
