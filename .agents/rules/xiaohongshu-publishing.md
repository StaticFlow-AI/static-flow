# Xiaohongshu (小红书) Anti-Throttling & Link Etiquette Rule (Hard Rule)

Whenever generating Xiaohongshu (`小红书`) post copy, slide images, or publishing notes via browser automation, strictly obey these anti-throttling (`防限流`) rules:

1. **Never Mention Any Link or Diversion in Title or Body (`正文绝不提任何文章链接`)**:
   - Never write `个人博客`, `已导入博客`, `全文见博客`, `链接放评论区`, `评论区置顶`, `见评论区`, `点击主页`, `私信获取`, or any external URL / domain name in the post title or body.
   - End the post body naturally as a self-contained technical note.
2. **Never Render Domains or Diversion Text on Slide Images (`配图严禁域名与导流字样`)**:
   - Xiaohongshu OCR scans all slide images. Never put `ackingliu.top`, `staticflow.cc`, any `.top`/`.com`/`.cc`/`.gg` domain, QR codes, or text like `完整精翻入库` / `链接见评论区` anywhere on cover or inner slides.
3. **Comment-Section Article Link Format (`评论区附链接规范`)**:
   - When adding an article link in the comment section, **never** post a standalone URL, **never** include `https://` or `http://`, and **never** use promotional/salesy hype (`🔗`, "速戳", "重磅干货", "快去我的博客看").
   - Embed the protocol-free address (e.g. `ackingliu.top/posts/<slug>`) naturally inside the middle of a calm, conversational paragraph explaining that because the original essay is long, a complete Chinese translation with clean reading typography is available there for anyone who wants to read the full text slowly.
4. **Skill Reference**:
   - Follow `skills/xiaohongshu-tech-note-publisher/SKILL.md` for visual style, character limits, and Creator Center publishing mechanics.
